# Acceptance Criteria

- Contrato de proveniência implementado e persistido/inspecionável.
- Validações: repository identity vs identity_key do workspace; paths
  normalizados; spans contra arquivos existentes; correspondência com
  snapshot; detecção de índice antigo (stale por mtime/hash de arquivo);
  arquivos removidos/modificados desde o índice; cross-workspace
  rejection; índice válido ≠ índice completo.
- Uso degradado explícito quando evidência de revisão é insuficiente —
  relações degradadas nunca promovidas como comprovadas.
- Testes cobrindo: correto, antigo, de outro repo, corrompido,
  incompleto, paths manipulados, spans inválidos, símbolos duplicados,
  encoding de posição divergente.
- Critério: índice incompatível nunca contamina snapshot READY.
