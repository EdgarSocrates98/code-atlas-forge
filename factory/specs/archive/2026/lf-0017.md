# Acceptance Criteria

- `resolvers/scip/` package: decoder.py (generic wire reader + scip message structs), importer.py (file→internal model), mapper.py (scip symbol/path → Atlas correlation), validation.py (index sanity + workspace/revision binding).
- Decoder: full wire-format reader (varints incl. >32bit, zigzag sint, fixed32/64, length-delimited, unknown-field skip); errors on truncation/malformed tags with field-path diagnostics.
- Importer: reads .scip bytes → documents + occurrences + symbol info; rejects oversized inputs (configurable limit), corrupt/unsupported versions; NEVER executes anything.
- Correlation: scip `relative_path` → Atlas file nodes via repository-relative path; symbol descriptor (scheme/package/descriptor) → Atlas symbol identity mapping layer — NOT assuming scip symbol == internal LogicalSymbol id; local symbols (local N) preserved as local.
- Revision/workspace validation: index metadata (project_root, tool info) checked against repo identity; refuse association when revision cannot be verified (e.g. index for different commit without explicit opt-in flag).
- `ScipResolver` implements SemanticResolver from lf-0016: resolves references/definitions from imported index; provenance records indexer tool+version; confidence_class=resolved only when symbol identity verified.
- Tests: golden .scip fixture (generated via fixture builder in-repo producing valid protobuf bytes — can synthesize bytes manually since schema is small), malformed/truncated indices, wrong-repo index rejection, definition+reference resolution e2e through coordinator.
- External-indexer policy: file path only (no command execution); size cap; documented limits.

# Constraints

- Zero new dependencies (stdlib only).
- No code execution from indexed repo or index files.
- Schema decode coverage documented: which scip.proto fields are interpreted vs skipped-and-preserved.

# Review Notes
