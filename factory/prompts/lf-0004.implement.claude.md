# Acceptance Criteria

- `code-atlas status [--json]` reports: root, repo id, branch + HEAD sha (or git-absent marker), snapshot state (none/BUILDING/READY/FAILED/STALE + counts), indexed file counts, `schema_version`, tool versions, warnings. Works before any index run.
- `code-atlas index [PATH] [--json] [--full]` runs the lf-0002 scanner, persists inventory via lf-0003 coordinator, prints summary (files, ignored, secrets excluded count, duration, snapshot id); `--full` forces re-scan of unchanged files; default is incremental. Emits a warning-free success only when snapshot reaches READY.
- `code-atlas --version`, `-h/--help` on root and each subcommand; help does not advertise unimplemented verbs; unknown command exits nonzero with usage hint.
- Consistent exit codes documented (e.g. 0 ok, 1 generic error, 2 usage, 3 unsafe/blocked) and implemented uniformly.
- `--json` outputs are single JSON objects on stdout, errors on stderr; no ANSI color in `--json` mode.
