# Review — lf-0022 (semantic CLI & query interfaces)

## Veredito: ACCEPTED

## O que foi entregue

- **Envelope v2** (`SCHEMA_VERSION="2"`): aditivo — `repository{id,
  root_handle, identity_key}`, `query`, `diagnostics[]` em todos os
  comandos de consulta; campos v1 preservados (compat).
- **`index`**: incremental é o **default** (decisão do grill gate);
  `--full` força rebuild. Payload ganha `plan` (counts
  reparse/reuse/revalidate) + `schema_version` + `diagnostics`.
- **`index-plan <path>`**: dry-run — scan + diff + `IndexPlan` JSON
  por arquivo com ação+razão, **zero writes** (verificado: snapshots
  count estável). Sem READY anterior → plano full sintetizado
  (`incremental=false`, diagnostic note).
- **`references`**: agora **incoming-only** (o símbolo é alvo,
  `o2.logical_symbol_id`); default REFERENCES+CALLS, `--relation-type`
  filtra outro tipo. Proveniência completa por aresta (resolver,
  confidence_class, resolution_status, evidence_ids).
- **`definitions`**: sites de definição (path/line/col/parse_status)
  via ocorrências do símbolo lógico.
- **`dependencies`**: arestas saíntes com BFS `--depth N` (default 1,
  teto duro `MAX_DEPTH=8` — 999 clampa, testado), cycle-safe via
  `visited`, budget de nós `MAX_LIMIT`, `truncated` honesto, depth por
  aresta na saída.
- **Invariantes**: SQL 100% parametrizado; `ambiguous`/`unresolved`
  nunca rotulados `resolved`; todas queries snapshot- e
  repository-scoped.
- **Testes** (`test_semantic_commands.py`, 15): E2E real — envelope
  fields, incremental default + plan counts, dry-run sem writes,
  definitions, incoming-only, depth 1/2 alcance, ciclo a→b→a, cap
  999→8, paginação+truncated, invariante ambiguous, help listando os
  novos verbos e vetando os futuros.

## Decisões registradas

- `references` incoming-only: spec explícita ("incoming REFERENCES/
  CALLS edges"); teste Cycle-2 existente já assertava aresta incoming
  e continua verde.
- `schema_version` bump justificado por mudança de shape aditiva.

## Verificação

- `pytest -q` → **294 passed** (279 + 15 novos)
- `ruff check src tests` → clean

## Riscos restantes

- `dependencies` carrega arestas em memória até `MAX_LIMIT` antes de
  paginar — bounded por design; repos muito densos pagam o cap.
- `definitions` não distingue def-site primário de ocorrências
  secundárias (schema não tem `role`) — documentado.
