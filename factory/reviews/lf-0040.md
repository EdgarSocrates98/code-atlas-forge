# Review — lf-0040 (context pack engine + token budget)

**Veredito: APPROVED** — packs determinísticos sem LLM, budget
respeitado com truncamento explícito, três níveis sem reconstruir
consulta, renderers JSON+Markdown versionados, CLI `context`.

## Findings (resolvidos durante implementação)

1. **Schema `relations`** — primeira query usava `edge_kind`/
   `src_occurrence_id`; colunas reais são `type`/`from_id`/`to_id`
   (LEFT JOIN p/ `to_id` NULL em unresolved). Corrigido.
2. **search_symbols minimal** — items só têm `{symbol_id, qname,
   lang, kind}`; `_occ_rows` batchado (json_each) busca occurrence +
   signature/docstring do FTS + path — sem N+1.
3. **Testes legados de "verbos futuros"** — `context` saiu da lista
   negativa (`mcp`, `serve`, `ui` permanecem pinados como futuros).
4. **mypy call-overload** — `int(obj)` sobre `dict[str, object]`;
   `int(str(...))` resolve sem ignore.

## Cobertura dos critérios

- Contratos completos: ContextRequest/Pack/Item/Evidence/Budget/
  Diagnostics/ExpansionRef/Manifest — campos task, repository,
  snapshot, budget, selected symbols, files, deps, evidence refs,
  ranking explanation, truncation, freshness.
- Níveis orientation(0)/focus(1)/deep(3) — depth de grafo distinto,
  mesma consulta; `expansion_refs` preservam IDs p/ disclosure.
- Budget: reservas meta/evidence/diagnostics (5/10/5%), política
  fit-in-order, omitidos registrados; indicadores insufficient_
  budget/mandatory_context_omitted/suggested_minimum_budget.
- Prioridade implementada: essential<direct<contract<dep<snippet<
  complement<transitive (constantes em contracts.py).
- Dedup por `kind:item_id`; IDs estáveis (testado determinismo).
- Ensaios 512/2000/4000/8000/16000: `spent <= available` pinado.
- Tokenizer heurístico (chars/4) + seam `TokenCounter`; `tokens_
  estimated=True` sempre — nunca contagem exata.
- Renderers `pack-json-v1`/`pack-markdown-v1` versionados.

## Riscos / limitações declaradas

- Estimador heurístico não é tokenizer de modelo real — erro uniforme,
  documentado; adapters reais via seam.
- `unresolved_refs` sempre vazio (deps externas/unresolved não entram
  como refs ainda — aparecem só como expansion_refs via grafo).
- Seeds de grafo limitados a 20; deps LIMIT 100 — cortes honestos.
