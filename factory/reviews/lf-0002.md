# Review: lf-0002 — Git-aware discovery scanner

Reviewer: Devin. Findings-first.

## Critérios

- [x] `code_atlas.discovery` expõe `scan(root) → ScanResult` com `SourceFile{path,language,size_bytes,sha256,ignored}` — caminhos POSIX relativos canônicos, linguagem por extensão, sha256 streaming.
- [x] Git detection: `probe_git` cobre branch, HEAD SHA, dirty (`git status --porcelain`), worktree (`--git-common-dir` ≠ `--git-dir` ou `.git` file) e modo `git_available=False` testado.
- [x] Tracked/untracked via `git ls-files -z -c / -o --exclude-standard`; ignorados via `-o -i --exclude-standard`; `.gitignore` honrado pela engine do git.
- [x] Fallback pure-python: `GitIgnoreStack` com escopo por dir, `**`, `!` negação (último match vence), `/` âncora, dir-only; modo rotulado `GIT_REPO_NO_BINARY`/`NO_GIT`.
- [x] Default ignores (.git, node_modules, __pycache__, .venv, dist, build, caches) podados; segredos (.env*, *.pem, *.key, id_rsa*, credentials*, *.p12/pfx…) **excluídos de hash e inventário**, só `secret_count`.
- [x] Symlinks: fora da raiz → warning `SYMLINK_ESCAPE`, nunca atravessados (testado arquivo e dir); dentro da raiz permitido; links circulares não travam (`followlinks=False` + teste).
- [x] Limites tipados: max_files (`LIMIT_FILES`+truncated), max_file_size (inventariado com sha256=None), max_depth (`LIMIT_DEPTH`), timeout (`TIMEOUT`+partial); Ctrl-C → partial.
- [x] Binários, UTF-8 malformado, unicode/espaços, nested .gitignore, negação, renomeados/deletados, traversal, worktree, branch switch — testados, sem crash.
- [x] Manifest determinístico: `manifest_bytes()` sem timestamps/abs paths; double-run byte-idêntico (git e no-git).
- [x] Sem execução de código do repo — teste `test_scanner_never_executes_repo_code` prova que um `setup.py` payload não roda; subprocess só invoca `git` argv, sem shell.
- [x] 12 categorias de teste do spec cobertas (29 testes novos).
