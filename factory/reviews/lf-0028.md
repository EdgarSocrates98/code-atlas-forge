  (format/sha256/producer/identity/worktree_digest/indexed_at/
  validation_status/evidence) + `assess_revision()` — sem executar

  - default sem provenance = degraded (índice não-verificado nunca
    é provado por default).
- `bootstrap._scip_factory`: assessment após load; rejected → erro
  tipado sem factory; degraded → factory + diagnóstico no payload.
- `docs/scip-integration.md` atualizado.

## Decisões registradas

- mtime como sinal de staleness é evidência host — marcada em
  `indexed_at`; hash por arquivo não entra no worktree_digest
  (size apenas) para não re-ler o repo inteiro no bootstrap.
- `source_revision` vazio: SCIP metadata não carrega commit —
  preencher seria inventar proveniência.

## Riscos restantes

- Staleness por mtime pode dar falso degraded em checkouts
  (git checkout atualiza mtime sem mudar conteúdo) — aceito:
  degraded é conservador, nunca silencioso.
- Assessment re-lê arquivos indexados para spans — O(docs), não
  O(repo).
