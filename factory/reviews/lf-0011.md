## Design decisions recorded

- `package`/`repository` graph nodes are NOT persisted as occurrences
  (no real path file) — containment derivable via `file_inventory` +
  path prefixes; documented in `persist.py` docstring.
- `edges_skipped` counts structural edges dropped for persistence
  (e.g. repo→package CONTAINS) — visible in stats, not silent.
- Parse runs before `BEGIN IMMEDIATE` — write lock stays short;
  content read after scan is the parsed truth (content_hash recorded).

## Remaining risks

- File content can drift between scan hash and read_bytes (bounded
  window; content_hash on evidence shows what was actually parsed).
- FTS populated only for newly-created symbols — deduped symbols keep
  their original fts rowid (stable across snapshots, intended).
- `symbols_new` counts only created rows; unchanged symbols reuse ids.
