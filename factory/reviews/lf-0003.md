# Review: lf-0003 — Domain contracts + SQLite storage + snapshot lifecycle

Reviewer: Devin. Findings-first.

## Critérios

- [x] `contracts.models`: dataclasses para as 8 entidades do Blueprint §5 — Repository, Snapshot (status/parent/analyzer_versions/worktree_digest), DomainSourceFile, LogicalSymbol, SymbolOccurrence (span/hash na ocorrência), Relation (resolver/confidence_class/resolution_status/evidence_ids), Evidence (extractor+version+content_hash), IndexJob.
- [x] `contracts.enums`: NodeKind/EdgeKind/ConfidenceClass/ResolutionStatus/SnapshotStatus casam o vocabulário do Blueprint **exatamente** (teste `test_enum_vocabularies_match_blueprint`); valores inválidos → ValueError via `__post_init__`.
- [x] `contracts.ports`: Protocols `RepositoryScanner`, `ParserAdapter`, `SymbolResolver`, `GraphStore`, `SearchPort`, `IndexCoordinator` — só assinaturas, sem implementações placebo (Cycle-1 reais: scanner/store/coordinator).
- [x] `storage.db.connect`: WAL, foreign_keys=ON, busy timeout (via `timeout=`), synchronous=NORMAL, row_factory=Row; modo read-only por URI.
- [x] `storage.migrations`: `schema_migrations` com checksum SHA-256, sequencial, idempotente (re-run limpo testado), drift detectado (testado); `schema_version` queryable.
- [x] Schema com todas as tabelas do Blueprint §6 + índices exigidos; `fts_symbols` FTS5 criada quando disponível (flag por `fts5_available`).
- [x] `IndexCoordinator.index`: transação única BUILDING→validate→READY; `publish_snapshot` marca anterior STALE na mesma tx; falha → rollback + snapshot FAILED separado + job failed; prior READY preservado (testado com falha injetada).
- [x] No-op determinístico: mesmo `worktree_digest` + mesmas `analyzer_versions` → job `noop`, nenhum snapshot/row extra (testado).
- [x] Dedup por conteúdo: `source_files` UNIQUE(repo,path) — reindex sem duplicar (testado).
- [x] Concorrência: 4 readers + writer sob WAL sem erro (testado); escritor único via `BEGIN IMMEDIATE`.
- [x] SQL parametrizado: auditoria AST estática reprova f-string/concatenação em `execute*` (teste dedicado).
- [x] Testes exigidos pelo spec: migrações, pragmas, lifecycle, falha-preserva-READY, idempotência, readers concorrentes, enums, provenance.

- `index_jobs` inserido dentro da transação sumia no rollback → job agora commitado antes do BEGIN IMMEDIATE; FAILED snapshot é inserido em transação separada (BUILDING abortado não existe para marcar).
- Thread-bound sqlite3 no teste de concorrência → conexão do writer criada na própria thread.

- P2: `symbols`/`relations`/`evidence` têm schema mas sem writers reais (spec: contract-only este ciclo).
- P2: `IndexCoordinator` expõe `_store` mutável — aceitável interno; teste usa para injeção de falha.
