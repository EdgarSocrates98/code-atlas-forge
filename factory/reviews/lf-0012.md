## Scope implemented

- `src/code_atlas/search/structural.py` — `StructuralSearch` over
  persisted storage: `repo_for_root`, `resolve_snapshot`
  (latest READY by default, explicit `--snapshot`, FAILED/missing →
  error string), `search_symbols` (substring LIKE + language/kind/path
  filters), `symbol_detail` (numeric id or qualified name +
  occurrences), `references` (relations touching a symbol, resolved
  `to` via LEFT JOIN on occurrences/symbols), `graph_dump` (all nodes
  + edges of a snapshot, deterministically ordered). Page model with
  `total`/`truncated`, `clamp_limit` (default 50, max 500).
  `SCHEMA_VERSION = "1"` on every payload.
- `src/code_atlas/storage/store.py` — `repo_id_by_root` lookup for
  root→repository resolution.
- `src/code_atlas/cli.py` — exactly 4 new commands: `search`, `symbol`,
  `references`, `graph`. Shared `_search_context` (root→repo→snapshot
  resolution), `_emit_error`, `_emit_page`, `_add_query_args`
  (--root/--snapshot/--limit/--offset/--json + per-command filters).
  Exit codes: 0 ok, 1 runtime error, 2 argparse, 3 unsafe.
- `tests/search/test_search_cli.py` — 7 E2E tests on a real
  multi-language fixture indexed through the CLI.

## Fixes during review loop

- `_search_context` returned stale `snap_id` variable (F821) → returns `snap.id`.
- Unused `Snapshot` import removed.
- `COUNT(*)` f-string-concatenated SQL moved to local var for AST audit.
- Two Cycle-1 help tests updated to accept the 4 now-real commands.
- `mypy` strict: payloads typed `dict[str, Any]`; `int(object)` on
  SQLite row resolved via typed row field; unused `type: ignore`s dropped.

## Remaining risks

- LIKE substring scan is O(symbols) per query — acceptable at Cycle-2
  scale; FTS5 table already exists as fallback/upgrade path (Cycle 3+).
- `references` on a symbol with thousands of relations is paginated;
  `graph` dump is not paginated by design (full snapshot export).
- No dedup of file-kind nodes in `search` results vs symbol nodes —
  both surfaces intentionally (file nodes carry path-only identity).

## Decision

PASS. Archive `lf-0012` with `--accepted`; dispatch lf-0013
(golden fixtures + eval + benchmarks).
