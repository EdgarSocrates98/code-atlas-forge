## Scope implemented

- `src/code_atlas/resolvers/scip/` — zero deps, nunca executa nada:
  - `decoder.py` — wire-format protobuf completo: varints LEB128
    (incl. 64-bit), zigzag sint, fixed32/64, length-delimited, packed
    repeated, skip por wire-type de campos desconhecidos. Erros com
    field-path (`Index.documents.occurrences...`). Groups (deprecated)
    rejeitados explicitamente.
  - `importer.py` — specs tipadas por mensagem + `parse_index` →
    `ScipIndex{documents, external_symbols, metadata}` com Occurrences
    normalizadas (single/multi-line range + deprecated packed range).
  - `loader.py` — política do indexer externo: entrada é path, cap de
    tamanho configurável (256 MiB default), `LoadOutcome` honesto
    (nunca levanta por input ruim).
  - `validation.py` — sanidade (paths, duplicatas, limites) +
    `project_root_matches` binding de revisão via file:// URI
    (percent-decode manual — urllib é banido pelo audit de rede).
  - `mapper.py` — parser da gramática de símbolo scip
    (scheme/manager/pkg/version + descriptors com sufixos
    namespace/type/term/method/param/meta/macro + `local N`) +
    `ScipCorrelator`: doc-path do namespace → ModuleCtx + membro final
    → nid; leaf/qname como fallback. Associação por identidade, nunca
    por id posicional.
  - `resolver.py` — `ScipResolver` (SemanticResolver, tier
    SEMANTIC_INDEX): occurrence-por-span → símbolo → correlator;
    `resolved` só com alvo único verificado; proveniência carrega
    tool+versão do indexer; conversão scip 0-based ↔ Atlas 1-based.
