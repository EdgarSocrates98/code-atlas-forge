## Falhas de CI encontradas e corrigidas no processo (sem redução de teste)

1. `test_synth_corpus_seed_changes_content` — comparação assumia paths
   idênticos entre seeds; dict rel→bytes.
2. LSP transport Windows — `select()` não aceita pipes; guard
   `os.name` + `os.read` bloqueante.
3. CI Windows travou ~20min: `os.close(fd)` com read pendente em outra
   thread trava; no Windows `close()` mantém reader vivo até o exit
   (`_LEAKED_READERS`, leak limitado e documentado).
4. `project_root_matches` — bug de produção real: `file:///C:/x`
   decodificava para `/C:/x` (diretório literal, não drive); fix no
   validation.py beneficia índices SCIP reais de Windows.
5. Audit test sem `encoding="utf-8"` — cp1252 quebrava no Windows.
