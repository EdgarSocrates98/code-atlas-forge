## O que foi entregue

real e verificados à mão):

- `py_advanced` — relative imports (`from . import u` + `from .u import

  `enabled=False` é o default.

**Dois bugs reais encontrados pelos fixtures e corrigidos**:

1. **Falso-positivo de shadowing**: `resolve_name` consultava
   `import_targets` antes de `defines` locais — `def helper()` que
   sombreia `from pkg.util import helper` resolvia para o alvo errado
   com status `resolved`. Sem ordem textual disponível, o desfecho
   honesto é `ambiguous` — implementado.
2. **Separador `..` em `from . import X`**: o extractor produzia
   `..util` → external/unresolved. Agora produz `.util` →
   `IMPORTS pkg.rel → pkg.util` resolved e `util.helper()` resolve.
   Bonus: `wildcard_import` agora emite aresta IMPORTS para o módulo
   (antes saía zero arestas — dependência invisível).

**Métricas estendidas** (`eval_harness` — buckets nunca agregados):
`resolver_metrics` (P/R por `relations.resolver`), `status_rates`
(resolved/ambiguous/unresolved/external com denominador explícito),
`false_positive` (só arestas `resolved` fora do ground truth; suprimido
em modo subset — denominador desonesto), `evaluate_incremental`
(canonical incremental×full + `reuse_symbol_ids_stable`).

**Security/portability (Phase 10)** — 5 testes novos em
`test_hardening.py`: env leak-minimizado não carrega segredos para o
server LSP; nenhum auto-download/install em src/ (audit AST);
timeouts LSP finitos e bounded; paridade Windows (audit proíbe
fcntl/pwd/grp/termios/resource/symlink em src); resolvers não executam
conteúdo do repo (cmd só de config do usuário).

## Riscos restantes

- `ambiguous` por falta de ordem textual é conservador — um resolver
  futuro com ordenação de bindings pode rebaixar para resolved→local
  corretamente (mudança de comportamento documentada no manifesto).
- Barrel reexports TS não são seguidos pelo resolver sintático —
  `Thing`/`otherFn` ficam honestamente unresolved (fixture asserta não-
  resolução; resolução exigiria chaining de export, fora de escopo).
- `large` é subset-mode: precision de relações é estruturalmente 0.01 —
  artefato do modo, não defeito (fp suprimido nesse modo).
