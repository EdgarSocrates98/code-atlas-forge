# Devin project config — code-atlas-forge

code intelligence graph and repository analysis.

- CLI: `code-atlas` (see AGENTS.md for the operating contract).
- Obsidian export: `code-atlas obsidian status|scan|preview|sync-plan|history` (read verbs pre-allowed in `config.json`; `export`/`export-note` mutate the vault and stay gated).
- `config.json` only declares `permissions` (repo-declarable keys); user-level settings are out of scope.
